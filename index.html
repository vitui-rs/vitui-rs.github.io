Layered terminal rendering with damage tracking, in Rust. The frame costs what is on the screen — never what is behind it.

Three crates, one claim

Section titled “Three crates, one claim”

Frame cost is proportional to visible cells, never to data volume. That is the engine’s invariant and it holds there without exception — a list of a million rows costs the rows you can see. Above the engine, a component that cannot know which of a million points land in its rectangle without looking at them splits the cost instead: the frame costs the rectangle, the edit costs the data, behind a memo, and both halves are gated.

vitui-engine is everything that touches the terminal — cells, surfaces, layers, compositing, damage, input and the bytes on the wire. vitui-runtime is everything above it — layout, identity, focus, hit-testing, routing, key maps, theming, overlays and the data contract. vitui-components is the widget library, and it is not privileged: every component in it is a plain function you could have written yourself.

A whole application

Section titled “A whole application”

This is a port of ratatui’s counter tutorial, and it is the entire program. The library holds no state, there is nothing to register, and a key nobody wants goes back on the queue.

Nothing between frames

No scene tree, no retained widgets, no diffing pass. The clip stack is the call stack and the id path is the closure tree. What survives a frame is five flat structures rebuilt from the next draw.

Damage at write time

Marked by the drawing verbs as they write, never derived by diffing two buffers — a full-buffer diff at 300×80 was measured at ~170 µs, which is already over the budget for a whole frame.

Budgets, not aspirations

Full-screen composition under 1 ms, a typical damage-tracked frame under 100 µs, zero allocations while a frame composes, zero wakeups when nothing happens. Each one is a CI gate.

Asked, not assumed

Eight terminal arms across seven emulator families, each driven live and photographed. Nothing shipped claims a terminal the suite has not run.

Status

Section titled “Status”

Released 2026-09-15 at 0.1.0, the first version with code in it; the 0.0.1 beneath each name is the placeholder it replaced. cargo add vitui is the short answer, and a clone of the repository is what runs the twenty-one applications, which are examples rather than part of the crate.
